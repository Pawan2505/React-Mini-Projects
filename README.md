# React Mini Projects

This repository contains a collection of **React mini projects** designed for practice and hands-on learning. These projects cover a variety of React concepts such as component-based architecture, state management, props, hooks, routing, form handling, and more. They are perfect for beginners and intermediate learners to strengthen their React skills.

## Projects Included

1. **react-accordion** – Accordion component with toggle functionality  
2. **react-card-with-props** – Card component using props  
3. **react-comment-review-app** – Comment and review management app  
4. **react-countdown** – Countdown timer app  
5. **react-form-handling** – Form handling and validation  
6. **react-image-slider** – Image slider/carousel  
7. **react-modal** – Modal popup implementation  
8. **react-navigator-app** – Navigation and routing app  
9. **react-password-visibility-toggle** – Toggle password visibility  
10. **react-profile-app-with-search** – Profile search app  
11. **react-profile-app** – User profile management  
12. **react-responsive-menu-with-submenu** – Responsive menu with submenu  
13. **react-responsive-menu** – Responsive navigation menu  
14. **react-tabs** – Tab component implementation  
15. **react-testimonial** – Testimonial carousel/app  

## Features Learned

- Component creation and reusability
- Props and state management
- Event handling in React
- Form handling and validation
- Using React hooks like `useState`, `useEffect`, etc.
- Conditional rendering and list rendering
- React Router for navigation
- Modal, accordion, tabs, and slider components
- Responsive design in React
